  prose and context before versus after case evidence from inputs that are
  proven byte-equivalent to the named source commit before launch.
- [ ] Every arm has an exclusive start receipt and appended end receipt, runs
  once without replacement, and preserves the fixed task, model, schema,
  context content, and strict first-cause scorer.

  prior-incident mention, memory disposition, and epistemic promotion before

  the proposal corpus, authorizing a scored baseline, or claiming product

## Finding

The owner-authorized reset campaign `q003-presentation-reset-20260909-v1` tested raw JSON and shipped prompt-guard prose both before and after C04 case evidence. All four newly identified arms ran once with complete source locks, exclusive start and appended end receipts, one unique ephemeral thread each, schema-valid responses, and no tool calls. A response-only blind review completed before treatment mapping was revealed.

Every treatment produced a current-incident-only first cause, omitted the prior CLI incident, mentioned without using the broader memory, and preserved H104 as proposed. Presentation format and position are therefore not sufficient to produce a cross-incident first cause for C04 under this current-client, single-case diagnostic.

This falsifies another rearrangement of the same context as the next C04 mechanism. It does not establish general product effect, estimate an effect size, authorize a scored baseline, lock version 4, or strengthen any hypothesis.
