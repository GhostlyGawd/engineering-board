# Common Thread synthetic brand specification

Source precedence is: this written specification, then `tokens.json`, then `logo-rules.json`, then current logo asset, then decorative examples. The obsolete logo and decorative examples never override written rules.

Common Thread sounds calm, specific, neighborly, and transparent. Prefer “member”, “host”, “local partner”, and concrete trip details. Avoid “exclusive”, “escape”, “bucket list”, “best-kept secret”, urgency, fake scarcity, unsupported environmental claims, and exclamation marks.

Use Fraunces for display copy and Inter for interface/body copy. Use the supplied modular type scale without arbitrary intermediate sizes. Headlines use sentence case. Body lines should remain between 45 and 72 characters on desktop.

Use only the six semantic color tokens. `coral-600` on `cream-50` is permitted for large decorative fields but fails normal-text contrast; normal text on cream must use `navy-900` or another verified accessible semantic pairing. Never introduce teal. Photography uses warm natural color, visible grain, square or 3:2 crops, and no gradient overlays. Illustration uses one-color line work.

Use only `assets/common-thread-logo.svg`. Keep it undistorted, unredrawn, and surrounded by clear space equal to the emblem width. Do not place it on a busy image.

The exact legal line in every pricing source and exported campaign metadata is: “Member prices include the cooperative service fee. Local taxes may apply.”

Prohibited patterns: glassmorphism, neon or purple gradients, pill-shaped body cards, more than one primary CTA per viewport, all-caps headings, fake testimonials, ratings, and logo recoloring outside the supplied variants.
