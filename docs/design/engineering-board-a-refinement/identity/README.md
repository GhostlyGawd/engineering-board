## Design decisions

Wordmark becomes the primary identifier; the card mark becomes secondary.
Show a compact two-line lowercase lockup and a horizontal application variant.
Keep the name unchanged. More deliberate kerning, narrower neo-grotesk forms,
open counters and distinctive letterforms should separate the brand from a
default bold UI label. This is proposed lettering, not a claimed custom font.

Separate four roles: brand lettering, medium-weight display, regular reading
text and mono record metadata. Strong brand weight should not spread into
every heading or body label. Show actual name at large and header scales.
The small application crop preserves Synthetic example, Read-only, Proposed
hypothesis and No outcome recorded. It is intentionally not the whole case.

Exact wordmark paths, typeface selection/license verification, font metrics,
small-size legibility, both themes, contrast and working interaction remain
prototype/asset-production checks after selection. No font is installed or
production vector changed in this step. Existing BRAND.md remains current.

References retained in references.md; prompt retained in prompt.txt. Built-in
Image Gen creates the identity specimen from A3 as palette/context input.
No source's claim of accessibility or product functionality is adopted.
