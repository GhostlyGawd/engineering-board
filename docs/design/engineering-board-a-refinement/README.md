## Craft commitments shared across options

- Preserve headline wording, findings, H001 Proposed hypothesis, Evidence,
  Alternative, Falsifier, No outcome recorded, source/back actions and first use.
- Keep Synthetic example adjacent to the upper preview and lower record. Keep
  Read-only visible. No fabricated outcomes, probabilities, metrics or live UI.
- Reduce wordmark scale, headline weight, CTA bulk, and oversized labels.
  Use a deliberate 60/28/16/13 type hierarchy, larger reading line-height, aligned
  baselines, 8px spacing rhythm, clear outer margins and restrained borders.
- Prioritize one primary action, a readable main record and subordinate metadata.
  Keep status neutral and explicitly textual. Only selected items use selection
  emphasis. Use one coherent icon stroke and a compact card-based mark.
- A raster mark or color is concept intent; retain exact vector/token production
  and responsive/keyboard/contrast checks for the selected prototype.
