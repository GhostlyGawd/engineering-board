02 / Start in your repository

Your first board.
A lasting record.

Install the plugin in Codex, then start a new session in your repository. Your board lives alongside your code.

Run these commands in your terminal, then initialize a board in your repository.

01

Add the Codex plugin

codex plugin marketplace add GhostlyGawd/engineering-board
codex plugin add engineering-board@engineering-board

You need Codex CLI and Python 3 available on your machine.

02

Start a new Codex session

Open the repository you want to use, then ask:

Initialize Engineering Board in this repository and show me the board location.

03

Check the result

Expect a repository-owned Markdown board. Ask Codex to show the board and its location. Then capture a real engineering observation when one arises.

If the board tools are missing

Confirm both installation commands completed, then start a new Codex session. Check that Python 3 is available. Ask Codex whether the Engineering Board MCP server is connected before retrying initialization.

Using Claude Code or another MCP client

In Claude Code, run these commands in order:

/plugin marketplace add GhostlyGawd/engineering-board
/plugin install engineering-board
/board-setup

After setup, /board-demo is an optional synthetic walkthrough in an isolated local directory.

Other MCP clients use the bundled Python server. See the client setup notes.
