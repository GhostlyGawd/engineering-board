# v1.12.0 release validation — 2026-07-31

## Outcome

Engineering Board v1.12.0 shipped on 2026-07-31.

An agent now receives the bounded canonical content of each selected memory
with its epistemic state, match reason, and source references. The agent no
longer needs a second provider-specific read to learn what the memory says.

This release does not claim that the new contract improves task outcomes. A
new non-scored Milestone D.1 preflight must test that product effect. The
version 4 corpus remains unlocked and cannot enter a scored run.

## Product boundary after release

Version 1.12.0 keeps canonical project memory in repository-owned Markdown.
The graph, context briefs, relevance scores, value report, cache, and generated
views remain derived data. This release does not add SQLite, embeddings,
telemetry, a hosted service, cross-repository aggregation, or Milestone E
work. It does not seal or execute the version 4 evaluation corpus.
