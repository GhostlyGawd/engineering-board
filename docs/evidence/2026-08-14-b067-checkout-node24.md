## Decision

Use the reviewed `actions/checkout@v7` major in all five checkout steps across
the four tracked workflow files. The official v7.0.1 release is current as of
2026-08-14, and the v7 action metadata declares the Node.js 24 runtime. V7 also
adds safer defaults for fork code in privileged triggers. This repository does
not use `pull_request_target` or `workflow_run`, and it does not opt out of the
safe default.

Preserve every existing trigger, permission, checkout input, and publication
gate. This change does not prepare or publish a release. It does not change a
product version, tag, checksum, bundle, package, or registry state.
